How this works

The page loads Pyodide, a build of Python that runs in the browser, installs Scapy, and imports the toolkit’s own nthunt package. There is no server and no separate copy of the detection logic, so the browser and the command line always give the same answers.

To run it from a terminal instead: python -m nthunt beacon capture.pcap. Captures from real incidents can contain live malware. Analyze the traffic, but don’t carve out and open files from it on your own machine.
